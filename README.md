# Omola Concept

A responsive, single-page website for **Omola Concept**, a fashion boutique in
Lagos, Nigeria. It introduces the brand, shows a gallery of collections, and
sends visitors to the boutique's Instagram.

## Sections
- **Hero:** full-screen banner with an Instagram call to action
- **Our Story:** about the brand
- **Instagram Gallery:** collection highlights (Summer Collection, New Arrivals, Accessories, Styling Tips)
- **Community:** Instagram follow banner
- **Contact:** address, contact details and store hours
- **Footer:** social links

## Features
- Responsive layout for mobile, tablet and desktop
- Mobile hamburger menu
- Smooth scrolling between sections
- A "back to top" button that appears as you scroll
- Hover animations on the gallery and buttons

## Built with
- HTML5
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- [Font Awesome](https://fontawesome.com/) icons
- Google Fonts (Playfair Display and Montserrat)
- Vanilla JavaScript
- Images from [Unsplash](https://unsplash.com/)

## Run it
There is nothing to install. Download or clone the repository and open
`index.html` in any web browser.

```bash
git clone https://github.com/Iredia23/omola-concept.git
```

## Put it online with GitHub Pages
1. In this repository, go to **Settings → Pages**.
2. Under **Branch**, choose `main` and `/ (root)`, then click **Save**.
3. After a minute or two the site is live at `https://iredia23.github.io/omola-concept/`.
